# CardioCare AI System

CardioCare AI is a Streamlit application that estimates cardiovascular disease risk from patient measurements. It presents model explanations and risk-based lifestyle and treatment guidance to support educational exploration.

## What it includes

- An XGBoost classifier and fitted scaler for inference
- A Streamlit interface for entering patient measurements and viewing results
- SHAP explanations that show how input features contribute to a prediction
- Risk-based guidance generated by the application

## Run locally

Requirements: Python 3.11 or later.

Create and activate a virtual environment, then install the project dependencies:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

On macOS or Linux, activate the environment with:

```bash
source .venv/bin/activate
```

Start the app from the project folder:

```bash
python -m streamlit run streamlit_app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser. The repository includes the trained XGBoost model and scaler required for inference.

## Run with Docker

Requirements: Docker Desktop (or Docker Engine) with Docker Compose v2 enabled.

Build and run the image:

```bash
docker build -t cvd-care-system .
docker run --rm -p 8501:8501 cvd-care-system
```

Open [http://localhost:8501](http://localhost:8501). The container exposes port `8501` and includes a health check.

Alternatively, use Docker Compose:

```bash
docker compose up --build
```

Stop the Compose app with `docker compose down`. To use a different host port, set `APP_PORT` before starting Compose.

PowerShell:

```powershell
$env:APP_PORT = "8502"
docker compose up --build
```

macOS or Linux:

```bash
APP_PORT=8502 docker compose up --build
```

Then open [http://localhost:8502](http://localhost:8502).

## Train the models

The processed dataset is not included in this repository. The training script expects it at `dataset/cardio_data_processed.csv`. Obtain the [Cardiovascular Disease dataset](https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset) separately and confirm you have permission to use it before training.

With the dataset in place and project dependencies installed, run:

```bash
python train.py
```

Training preprocesses the data, fits the models, updates `scaler.pkl`, and copies the trained XGBoost model to `xgboost.pkl` for the Streamlit app.

## Project files

```text
Dockerfile                 Docker image definition
compose.yaml               Docker Compose service
requirements.txt            Local development and training dependencies
requirements-docker.txt     Pinned dependencies for the Docker image
streamlit_app.py            Streamlit user interface
train.py                    Model training entry point
utils/                      Preprocessing, explanations, and guidance
xgboost.pkl                 Trained XGBoost model used by the app
scaler.pkl                  Fitted feature scaler used by the app
dataset/                    Place the processed training data here
```

## Use note

This application is a demonstration based on a public dataset. Its output is an estimate of the dataset's cardiovascular disease label, not a diagnosis, prescription, or substitute for advice from a qualified healthcare professional.

## Deploy on Vercel

Vercel uses `Dockerfile.vercel` to run the Streamlit app in its container runtime. In the Vercel project settings, set the `PORT` environment variable to `8501` for each deployment environment you use (Production, Preview, and Development). Keep the project root directory set to the repository root, then redeploy from the `main` branch.

The container listens on the configured `PORT` and supports Streamlit's interactive WebSocket connection. The container runtime requires a Vercel plan/project with container deployments enabled.
